# Congratulations!

You have successfully set up a fully authenticated Obot instance, added a GitHub MCP server, connected an AI client through the Obot gateway, and verified tool calls in the audit log.

- How to run Obot with authentication enabled using Docker
- How to configure Google or GitHub as an authentication provider
- How to add the GitHub MCP server from the built-in catalog

- How to call GitHub MCP tools from Claude (e.g. list repositories)
- How to view and interpret MCP activity in the Obot audit log
